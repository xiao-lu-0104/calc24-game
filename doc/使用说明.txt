========================================================================
              计算 24 点游戏  ——  使用说明（Windows 图形界面版）
========================================================================

【界面版本】V2.0「界园终端」卡片式主题。深蓝灰底 + 米白卡片 + 品红强调，
            自绘切角卡片、条形码、菱形徽标与竖向标题；扑克牌、进度条、
            按钮、复选框全部由 GDI 手绘，窗口可以像普通软件一样最小化、
            最大化、拉伸缩放，缩放时保持等比不留黑边。

二、编译方法
   【Dev-C++】打开 src\计算24点游戏.cpp，
              工程属性 → 参数 → 链接器 中加入  -lgdi32 -mwindows  后按 F11。
   【VS Code】打开本文件夹，Ctrl+Shift+B 构建，F5 调试运行。
              需先在本机安装 MinGW-w64（g++）并把它的 bin 目录加进 PATH。
   【Visual Studio】新建 Windows 桌面向导 → 添加现有项 src\计算24点游戏.cpp → Ctrl+F5。
   【命令行】先在 src 目录下把声音打包成资源：
              windres 计算24点游戏.rc -O coff -o 资源.o --codepage=936
           再编源程序（在仓库根目录执行）：
              g++ -std=c++11 -O2 -mwindows -o 计算24点游戏.exe ^
                  src\计算24点游戏.cpp src\资源.o -lgdi32 -lwinmm
   注意 1：-mwindows 表示生成窗口程序（不带黑色控制台窗口），不能省略；
           -lwinmm 是 MCI 音频所需的链接库，缺了会报 mciSendStringA 未定义。
           资源.o 和 --codepage=936 是用来把中文文件名的 mp3 打进 exe 的，
           不需要内嵌声音时可以不链资源.o，程序会只找外置的 音频\ 目录。
   注意 2：源文件为 GBK 编码，用 VS Code 打开请选择「通过编码重新打开 → GBK」，
           否则中文注释和字符串会显示为乱码（编译出来也是乱码）。
           ★ 千万不要把源文件另存为 UTF-8，否则中文字符串会被破坏。
   注意 3：程序只使用 Windows 自带 API，不需要任何第三方库或运行时。

三、运行须知
   1. 可执行文件就是普通的 Windows 窗口程序：有标题栏、最小化 / 最大化 /
      关闭按钮和菜单栏，可以随意摆放、缩放。
      界面按 1280×800 的设计画布绘制，窗口缩放时整体等比放大铺满客户区，
      两侧只留极窄的边，文字与线条在 125% / 150% 高分屏下依然清晰。
   2. rank.txt 与可执行文件放在同一目录即可。程序用 GetModuleFileName 取得
      自身所在目录来定位数据文件，因此从任意目录、快捷方式启动都不会丢数据。
      声音优先用 exe 旁的 音频\ 目录，找不到时自动用 exe 里内嵌的副本
      （首次运行时解到 %TEMP%\Calc24Sfx\），所以只发一个 exe 过去也有声音。
   3. 排行榜按「总分降序、用时升序」排序，最多保留 50 条。
   4. 同一玩家只保留个人最好成绩，不会出现两条同名记录。
   5. 若排行榜文件被删除，程序会自动重建，不会报错。

四、功能与操作
   鼠标点击为主，答题时用键盘输入表达式；
   任何子界面按 Esc 返回主菜单，对局中按 M 可开关声音。

   主界面（界园终端）：
     顶部右侧     系统时间、总分 / 最高分 / 当前难度 三项统计
     左上角图标   音效开关 / 游戏规则 / 排行榜 / 玩家档案
     左侧竖排     游戏标题「二十四点」、等级徽章 Lv、玩家名与 ID、
                  VOICE 台词框、BEST RECORD 最高分
     中间大卡片   「TERMINAL 01」开始对局：先登记姓名（留空记为「玩家」，
                  可跳过），再开始一局 3 题；卡片上直接显示当前难度、
                  每题限时和单题满分
     难度设置     「简单 / 普通 / 困难」三段开关，点一下即时切换
     玩家档案     显示玩家名、历史最高分、记录条数；点进去可改名（不开始新局）
     排行榜       查看榜上成绩（含难度列）
     游戏规则     查看规则说明
     训练战报     显示记录条数与历史最高分
     关于         版本与赛题信息
     退出         关闭程序
     左下角       音效开 / 关、每局题数

   答题：
     * 每局 3 题，每题随机发 4 张牌，点数取 1～10（1 显示为 A），四张牌可以重复。
     * 题目保证全程用整数四则运算就能算出 24，不需要分数，表达式里也不能写小数。
     * 在输入框中键入四则运算表达式（可用括号），按回车或点「提交」。
     * 只允许 + - * / 和括号，四个数字必须且只能各用一次。
     * 支持全角符号（＋ － × ÷ （ ）），会自动转换成半角。
     * 语法错误或数字不匹配时在输入框下方给出红色提示，可以继续作答，
       计时不暂停，也不扣分。
     * 若认为四张牌无解，勾选「本题无解」后再提交；判断正确同样得分。
     * 超时自动判负，本题 0 分，直接进入下一题。
     * 三题做完自动进入结算界面，显示总分、评价、每题用时与得分、
       榜上名次，并可直接「再来一局」或「查看排行榜」。

   计分（难度越高，分数越高）：
     单题得分 = 基础分 + 时间奖励 × 剩余秒数 ÷ 本题限时
        简单：60 + 40   →  单题满分 100（每题限时 60 秒）
        普通：80 + 50   →  单题满分 130（每题限时 40 秒）
        困难：100 + 60  →  单题满分 160（每题限时 25 秒）
     一局满分依次为 300 / 390 / 480 分。
     即同样是「秒答」，困难比简单多得 60% 的分数，鼓励挑战高难度；
     而用时越长得分越低，鼓励尽快作答。得分为 0 的成绩不记入排行榜。

   声音（MP3，用 MCI 异步播放，不会卡界面）：
     · 点击「开始游戏」   →  「叮叮叮」一声
     · 一整局开始时       背景音乐从头循环播放
     · 答题时间过半       →  「阿姨你快一点啦阿姨」
     · 本题答对（含无解判断正确）→「嘿嘿」
     · 本题答错 / 超时    →  「你干嘛哎哟」
     · 一局三题全对       →  「牛逼啊这个人 有操作的呀」
     · 有一题没答对       →  「哎呀」
     音效播放时背景音乐自动暂停，音效放完立即从原位置继续；
     后一个音效会打断前一个；返回主菜单或退出时背景音乐停止。
     演示时可在「游戏 → 播放声音」去钩一键静音，或点左下角「音效」卡片。

五、算法与实现要点（答辩要点）
   1. 判定四张牌能否算出 24：递归枚举「取两个数做一次运算」的全部组合，
      每层有 C(n,2) 对数字 × 6 种运算顺序，直到只剩一个数时判断是否等于 24。
      该搜索是完备的，因此可以准确判定「无解」。
   2. 全程使用有理数（分数）精确运算，不用 double，避免 8/(3-8/3) 这类
      依赖中间分数的题目因浮点误差被误判。分子分母均为 long long，
      每步约分，四个牌面在 1~10 之间时不会溢出。
   3. 出题时额外要求「只用整数中间结果即可解出」，保证玩家不需要写分数，
      规则与题面一致（约 1.2% 只能靠分数求解的题目会被剔除，重新发牌）。
   4. 玩家表达式用递归下降法解析：表达式 → 项 → 因子，与求解器共用同一套
      分数运算，因此判定标准与出题标准完全一致。
   5. 出题采用「拒绝采样」：要出有解题就一直随发直到求解器判定有解，
      要出无解题就一直随发直到判定无解，保证每题性质确定。
   6. 界面为纯 Win32 API + GDI 自绘：
        · 窗口、菜单、标题栏由系统提供，客户区完全自绘；
        · 每次 WM_PAINT 先画到内存位图再一次性 BitBlt 到屏幕（双缓冲），
          因此窗口缩放、遮挡恢复时都不会闪烁；倒计时刷新只重画那一条区域，
          不整屏重绘，进一步避免画面跳动；
        · 采用 MM_ANISOTROPIC 映射模式，所有坐标按 1280×800 的设计画布书写，
          再按客户区大小与显示器 DPI 统一缩放；
        · 按钮、复选框、扑克牌、进度条、卡片描边均为自绘，鼠标命中测试
          同样经逻辑坐标换算，缩放后点击位置依然准确；
        · 输入框用系统 EDIT 控件，通过 WM_CTLCOLOREDIT 改为深色配色，
          并子类化拦截回车键作为「提交」。

六、内置自检
   在命令行中执行：  计算24点游戏.exe --selftest
   程序会运行 25 项算法、解析器与素材检查，并随机生成 20000 组题目做自洽性验证。
   追加 --log 可把结果写入 selftest.log。全部通过时退出码为 0。
   另可用         计算24点游戏.exe --shots
   把七个界面各导出一张 2 倍分辨率截图（gui_*.bmp），用于写报告。
