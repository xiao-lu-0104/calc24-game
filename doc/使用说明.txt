              计算 24 点游戏  ——  使用说明（Windows 图形界面版）

一、文件清单

                          ★ 声音已经打包进 exe，单独拷这一个文件给别人也能出声
   rank.txt               排行榜数据文件（程序自动读写，可删除）
   音频\                  可选：如果想换声音，在 exe 旁边放同名 mp3 即可覆盖内嵌副本
       背景音乐.mp3             整局循环播放的背景音乐

       你干嘛哎哟.mp3           本题答错 / 超时时播放

   src\计算24点游戏.c++    源程序提交副本（内容与 .cpp 完全相同）

二、编译方法
   【Dev-C++】打开 src\计算24点游戏.cpp，
              工程属性 → 参数 → 链接器 中加入  -lgdi32 -lwinmm -mwindows  后按 F11。
   【Visual Studio】新建 Windows 桌面向导 → 添加现有项 src\计算24点游戏.cpp → Ctrl+F5。
   【命令行】在项目根目录下执行（rc 里的音频路径相对于根目录）：
              windres src\计算24点游戏.rc -O coff -o src\资源.o --codepage=936
              g++ -std=c++11 -O2 -mwindows -o 计算24点游戏.exe src\计算24点游戏.cpp src\资源.o -lgdi32 -lwinmm
   注意 1：-mwindows 表示生成窗口程序（不带黑色控制台窗口），不能省略；
           -lwinmm 是 MCI 音频所需的链接库，缺了会报 mciSendStringA 未定义。
           src\资源.o 和 --codepage=936 是用来把中文文件名的 mp3 打进 exe 的，
           不需要内嵌声音时可以不链资源.o，程序会只找外置的 音频\ 目录。
   注意 2：源文件为 GBK 编码，用 VS Code 打开请选择"通过编码重新打开 → GBK"，
           否则中文注释显示为乱码（不影响编译）。
   注意 3：程序只使用 Windows 自带 API，不需要任何第三方库或运行时。

三、运行须知
   1. 可执行文件就是普通的 Windows 窗口程序：有标题栏、最小化 / 最大化 /
      关闭按钮和菜单栏（游戏 / 帮助），可以像其它软件一样随意摆放、缩放。
      最大化时界面会等比放大铺满屏幕，两侧只留极窄的边，不会变形。
   2. rank.txt 与可执行文件放在同一目录即可。程序用 GetModuleFileName 取得
      自身所在目录来定位数据文件，因此从任意目录、快捷方式启动都不会丢数据。
      声音优先用 exe 旁的 音频\ 目录，找不到时自动用 exe 里内嵌的副本
      （首次运行时解到 %TEMP%\Calc24Sfx\），所以只发一个 exe 过去也有声音。
   3. 排行榜按"总分降序、用时升序"排序，最多保留 50 条。
   4. 同一玩家只保留个人最好成绩，不会出现两条同名记录。
   5. 若排行榜文件被删除，程序会自动重建，不会报错。

四、功能与操作
   全部用鼠标点击，答题时用键盘输入表达式，回车即可提交。

   菜单栏：
     游戏 → 开始新游戏 / 难度设置 / 高手排行榜 / 播放音效（可勾选）/ 退出
     帮助 → 游戏规则 / 关于

   主菜单：
     开始游戏      先输入姓名（留空记为“玩家”，可点“跳过”），再开始一局 3 题
     难度设置      简单 60 秒 / 普通 40 秒 / 困难 25 秒（每题限时）
     高手排行榜    查看榜上成绩（含难度列）
     游戏规则      查看规则说明
     退出游戏

   答题：
     * 牌面点数取 1～10（1 显示为 A），四张牌可以重复。
     * 题目保证全程用整数四则运算就能算出 24，不需要分数，表达式里也不能写小数。
     * 在输入框中键入四则运算表达式（可用括号），按回车或点「提交」。
     * 只允许 + - * / 和括号，四个数字必须且只能各用一次。
     * 支持全角符号（＋ － × ÷ （ ）），会自动转换成半角。
     * 语法错误或数字不匹配时在输入框下方给出红色提示，可以继续作答，
       计时不暂停，也不扣分。
     * 若认为四张牌无解，勾选「本题无解」后再提交；判断正确同样得分。
     * 每局三题，其中必然有 1 道无解题（随机安排在第几题）。
     * 每答完一题点「下一题」进入下一题，三题做完自动进入结算界面。

   计分（难度越高，分数越高）：
     单题得分 = 基础分 + 时间奖励 × 剩余秒数 ÷ 本题限时
        简单：60 + 40   →  单题满分 100
        普通：80 + 50   →  单题满分 130
        困难：100 + 60  →  单题满分 160
     一局满分依次为 300 / 390 / 480 分。
     即同样是"秒答"，困难比简单多得 60% 的分数，鼓励挑战高难度；
     而用时越长得分越低，鼓励尽快作答。得分为 0 的成绩不记入排行榜。

   声音（MP3，用 MCI 异步播放，不会卡界面）：
     · 点击“开始游戏”  →  “叮叮叮”一声
     · 一整局开始时  背景音乐从头循环播放
     · 答题时间过半  →  "阿姨你快一点啦阿姨"
     · 本题答对（含无解判断正确）→  "嘿嘿"
     · 本题答错 / 超时  →  "你干嘛哎哟"
     · 一局三题全对  →  "牛逼啊这个人 有操作的呀"
     · 有一题没答对  →  "哎呀"
     音效播放时背景音乐自动暂停，音效放完立即从原位置继续；
     后一个音效会打断前一个；返回主菜单或退出时背景音乐停止。
     演示时可在【游戏 → 播放声音】去钩一键静音。

五、算法与实现要点（答辩要点）
   1. 判定四张牌能否算出 24：递归枚举"取两个数做一次运算"的全部组合，
      每层有 C(n,2) 对数字 × 6 种运算顺序，直到只剩一个数时判断是否等于 24。
      该搜索是完备的，因此可以准确判定"无解"。
   2. 全程使用有理数（分数）精确运算，不用 double，避免 8/(3-8/3) 这类
      依赖中间分数的题目因浮点误差被误判。分子分母均为 long long，
      每步约分，四个牌面在 1~13 之间时不会溢出。
   3. 玩家表达式用递归下降法解析：表达式 → 项 → 因子，与求解器共用同一套
      分数运算，因此判定标准与出题标准完全一致。
   4. 出题采用"拒绝采样"：要出有解题就一直随发直到求解器判定有解，
      要出无解题就一直随发直到判定无解，保证每题性质确定。
   5. 界面为纯 Win32 API + GDI 自绘：
        · 窗口、菜单、标题栏由系统提供，客户区完全自绘；
        · 每次 WM_PAINT 先画到内存位图再一次性 BitBlt 到屏幕（双缓冲），
          因此窗口缩放、遮挡恢复时都不会闪烁；
        · 采用 MM_ANISOTROPIC 映射模式，所有坐标按 1040×700 的设计画布书写，
          再按显示器 DPI 统一缩放，高分屏下文字与线条依然清晰；
        · 按钮、复选框、扑克牌、倒计时进度条均为自绘，鼠标命中测试
          同样经逻辑坐标换算，缩放后点击位置依然准确；
        · 输入框用系统 EDIT 控件，通过 WM_CTLCOLOREDIT 改为深色配色，
          并子类化拦截回车键作为"提交"。

六、内置自检
   在命令行中执行：  计算24点游戏.exe --selftest
   程序会运行 22 项算法与解析器检查，并随机生成 20000 组题目做自洽性验证。
   全部通过时退出码为 0。
